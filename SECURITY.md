# Security policy

Please report vulnerabilities privately through
[GitHub security advisories](https://github.com/ardacoskun/codehop/security/advisories/new)
rather than public issues. You will get a reply within a week.

codehop runs your configured editor and, for `gh:`/git URLs, `git clone`. Shell
integration and `[actions]` insert the commands from your own config into your
shell; treat the config file like the rest of your shell configuration.
